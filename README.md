# Star Pattern Practice in Python

A Jupyter notebook with 6 star pattern problems solved using nested `for` loops, each with code and printed output. Pattern problems are a good way to build loop logic and control over rows, columns and spacing.

## Patterns covered

| # | Pattern | Concepts practiced |
|---|---------|--------------------|
| 1 | Right-angled triangle | Nested loops, `print(end=" ")` |
| 2 | Right-aligned triangle (using `0` as filler) | Spacing loops, row-wise logic |
| 3 | Triangle followed by an inverted triangle | `range()` with negative step |
| 4 | Right-aligned pattern (variation) | Controlling loop counts |
| 5 | Mirrored pattern with leading spaces | Combining space and star loops |
| 6 | Right-aligned triangle followed by its mirror (arrow shape) | Two-part loops, symmetry |

## What I learned
- How the outer loop controls rows and the inner loop controls columns
- Printing on the same line with `end=" "` and moving to a new line with `print()`
- Using spaces and reverse loops to build aligned and symmetric shapes

## How to run
1. Open `TOP_6_STAR_PATTERN_QUESTIONS.ipynb` in [Google Colab](https://colab.research.google.com/) or Jupyter Notebook.
2. Run the cells from top to bottom.
